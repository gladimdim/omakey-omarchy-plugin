# Omakey 1.4.0 — Omarchy plugin & Steam Deck 🌙

*Released October 10, 2026* · [GitHub release](https://github.com/gladimdim/omakey-omarchy-plugin/releases/tag/v1.4.0) · [Android app 1.4.0](https://github.com/gladimdim/omakey-mobile/releases/tag/v1.4.0)

## ✨ What's new

### 🌙 Wake on LAN
Your phone can now wake a sleeping computer.

- ⚙️ Turn it on in the bar widget: **Settings → Wake on LAN → Turn on**. Or run `omakeyd wake-on-lan on`.
- 🔑 It asks for your password once, because the network card's setting needs root. It stays on after a reboot.
- 📱 Open the computer in the Omakey app and, if it doesn't answer, the phone sends it a Wake-on-LAN packet. The status says **Waking…**, and the keyboard connects as soon as the computer is up.
- 📶 **Wi-Fi** wakes the computer from sleep, not from power-off, and only if the Wi-Fi card supports it; `omakeyd wake-on-lan` tells you.
- 🔌 **Ethernet** can also wake it from power-off, if Wake-on-LAN is on in its firmware (BIOS/UEFI) settings.
- 🏠 The phone has to be on the same network.
- 🔁 Phones paired earlier learn it the next time they connect. `omakeyd wake-on-lan off` turns it off again.

### ⚙️ Settings, on a page of its own
- ⚙️ A gear in the widget's header opens **Settings**, with a **←** back button. Esc goes back too.
- 🧾 Settings has Wake on LAN, the name your phone shows, the UDP port, this computer's addresses, and the plugin and `omakeyd` versions.
- 🧹 The grey address line is gone from the main page.

### 📱 Get the iPhone app from the bar
**Android app** and **iPhone app** buttons, side by side. Each shows a QR code to scan with your phone's camera, with **Open in browser** and **Copy link**. The iPhone app is open source and built in Xcode (iOS 17+); its link has the source and the build steps.

### 🟢 Green means connected
The dot next to **Omakey** and next to a connected phone is green, whatever your theme.

## 🛠️ For tinkerers
- `omakeyd wake-on-lan [on|off]`, and a Wake-on-LAN line in `omakeyd status`.
- WELCOME's feature bit 2 and `wake_mac`, and the pairing link's `w=`, are in [PROTOCOL.md](https://github.com/gladimdim/omakey-omarchy-plugin/blob/main/docs/PROTOCOL.md#wake-on-lan). Phones and servers from before 1.4 work with 1.4 as before.

## ⬆️ How to update

- **Omarchy:** update the plugin (`omarchy plugin update gladimdim.omakey`), then click **Update the service** in the bar widget.
- **Steam Deck:** run the install command again:
  ```bash
  curl -fsSL https://raw.githubusercontent.com/gladimdim/omakey-omarchy-plugin/main/install-steamos.sh | bash
  ```
  To turn on Wake on LAN, run `~/.local/bin/omakeyd wake-on-lan on` in Konsole (it needs a sudo password; set one with `passwd`).
- **Phone:** install [Omakey 1.4.0](https://github.com/gladimdim/omakey-mobile/releases/tag/v1.4.0); it updates in place and keeps your pairings.
