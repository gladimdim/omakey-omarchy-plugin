# Omakey 1.2.1 — Omarchy plugin & Steam Deck 🔒

*Released October 9, 2026* · [GitHub release](https://github.com/gladimdim/omakey-omarchy-plugin/releases/tag/v1.2.1) · [Android app 1.2.1](https://github.com/gladimdim/omakey-mobile/releases/tag/v1.2.1)

## 🔒 Security fix: one computer, several users

Your phone now types only into **your** session.

- 👥 Before, if you stayed logged in and someone else switched to their own account on the same computer, a phone paired with yours could still type into theirs.
- 🛑 Now `omakeyd` watches who is in front at the seat. The moment another user switches in, it stops typing and removes its virtual keyboard and mouse.
- 🔁 Switch back and they return; keys still held on the phone are pressed again. The phone stays connected the whole time.
- 🔐 Locking your own screen is unchanged: your session stays in front, so you can still type your password from the phone.
- 💬 `omakeyd status` says `Keyboard: away` while another user's session is in front.

## 🧰 Also

- ⚡ **One-command install** on Omarchy; `install.sh` installs Rust itself if it's missing.
- 📱 The README links the latest Android APK, with a QR code to scan.

## ⬆️ How to update

- **Omarchy:** update the plugin, then click **Update the service** in the bar widget (or run `~/.config/omarchy/plugins/gladimdim.omakey/install.sh`).
- **Steam Deck:** run the install command again:
  ```bash
  curl -fsSL https://raw.githubusercontent.com/gladimdim/omakey-omarchy-plugin/main/install-steamos.sh | bash
  ```
- **Phone:** nothing to do.
