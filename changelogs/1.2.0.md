# Omakey 1.2.0 — Omarchy plugin & Steam Deck 🎉

*Released October 8, 2026* · [GitHub release](https://github.com/gladimdim/omakey-omarchy-plugin/releases/tag/v1.2.0) · [Android app 1.2.0](https://github.com/gladimdim/omakey-mobile/releases/tag/v1.2.0)

## ✨ What's new

### 📋 Shared clipboard
Your phone and your computer now share one clipboard.

- ✂️ **Copy** on the phone copies what's selected on the computer — and the text lands on your phone too.
- 📥 **Paste** on the phone pastes on the computer. If you copied something newer on the phone, that's what gets pasted.
- 🔒 Passwords stay marked as sensitive, so clipboard managers skip them.
- ⚡ It never slows down typing: the clipboard is handled in the background.
- 🧩 Works with `wl-copy`/`wl-paste` (Omarchy has them) or KDE's clipboard.

### 🎮 Steam Deck with SteamOS
Omakey now runs on a stock Steam Deck — no Omarchy needed!

- 🚀 **One command, no sudo, no compiler.** In Desktop Mode, open Konsole and run:
  ```bash
  curl -fsSL https://raw.githubusercontent.com/gladimdim/omakey-omarchy-plugin/main/install-steamos.sh | bash
  ```
- 🕹️ Works in **Game Mode** and **Desktop Mode**: keyboard, touchpad, Bluetooth fallback.
- 📱 Pair from **Omakey: pair a phone** in the app menu or your Steam library.
- 🛡️ Everything lives in your home folder, so SteamOS updates won't remove it.
- 📋 The shared clipboard works in Desktop Mode; in Game Mode, Copy and Paste press the keys.

### 🎨 New bar icon
The bar icon is now the Android app's colourful icon. Its signal waves light up 💚 while a phone is connected.

## 🔧 Under the hood

- New `CLIP` / `CLIP_REPLY` packets, documented in `docs/PROTOCOL.md`, with test vectors. Older apps and services just don't use them.
- Every release now ships a static `omakeyd` build for SteamOS, built and tested by GitHub Actions.

## ⬆️ How to update

- **Omarchy:** update the plugin, then click **Update the service** in the bar widget (or run `~/.config/omarchy/plugins/gladimdim.omakey/install.sh`).
- **Steam Deck:** run the install command above.
- **Phone:** install [omakey-1.2.0.apk](https://github.com/gladimdim/omakey-mobile/releases/download/v1.2.0/omakey-1.2.0.apk) — it updates in place and keeps your pairings.
