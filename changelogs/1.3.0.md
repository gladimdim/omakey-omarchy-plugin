# Omakey 1.3.0 — Omarchy plugin & Steam Deck 📱

*Released October 9, 2026* · [GitHub release](https://github.com/gladimdim/omakey-omarchy-plugin/releases/tag/v1.3.0) · [Android app 1.3.0](https://github.com/gladimdim/omakey-mobile/releases/tag/v1.3.0)

## ✨ What's new

### 📱 Get the Android app from the bar
The bar widget now has a **Get the Android app** button.

- 📷 It shows a QR code for the latest Omakey APK: scan it with your phone's camera, download, install.
- 🌐 **Open in browser** and **Copy link** are right below it.
- 🧩 It works before the service is even set up, when you need it most.
- 🔁 During pairing it takes the pairing code's place; **Back to pairing** brings the code back.

## 🔒 Also in this line

- 1.2.1's fix is here too: `omakeyd` types only while your session is in front at the seat, so a phone paired with your account can't type into another user's session.

## ⬆️ How to update

- **Omarchy:** update the plugin (`omarchy plugin update gladimdim.omakey`), then click **Update the service** in the bar widget.
- **Steam Deck:** run the install command again:
  ```bash
  curl -fsSL https://raw.githubusercontent.com/gladimdim/omakey-omarchy-plugin/main/install-steamos.sh | bash
  ```
- **Phone:** install [Omakey 1.3.0](https://github.com/gladimdim/omakey-mobile/releases/tag/v1.3.0); it updates in place and keeps your pairings.
